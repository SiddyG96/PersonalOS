# PersonalOS

**Welcome to Sid OS**
SidOS is a personal web operating system designed to display my hobbies, aspirations, and interests, as well as one more misc app.

NOTE/DECLARATION OF AI USAGE
  - Used for debugging the openWindow/closeWindow functions as well as modifying the handleAppClick logic
  - Assisted me when writing code for the Atari-based Pong game

**APP DESC.**

Mini-Portfolio
  - A portfolio where I tell you a bit about myself
  - Containing my Hobbies, Classes I am taking, and my future aspirations
  - At the end, I ramble on a bit (please excuse this; possibly a product of journaling random things, and it is written based on my opinions--Please don't take it to heart)

Pong Game
  - Get 11 to win the game
  - Controlled using W and S (I recommend constantly tapping each button rather than holding it down)
